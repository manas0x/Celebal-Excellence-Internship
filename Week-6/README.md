# Week 6 – Spark Fundamentals 🚀

> **Celebal Technologies Internship – Week 6 Assignment**

This repository contains the solutions for **Week 6** of the **Celebal Technologies Internship**. The assignment focuses on understanding **Apache Spark Architecture**, **PySpark DataFrame operations**, **schema handling**, **file formats**, and **performance optimization techniques**.

---

## 📌 Assignment Information

- **Internship:** Celebal Technologies Internship
- **Week:** 6
- **Topic:** Spark Fundamentals
- **Language:** PySpark (Python)
- **Notebook:** Jupyter Notebook

---

## 🎯 Objective

The objective of this assignment is to understand Spark architecture and perform efficient data processing using transformations, filtering, schema handling, and optimized file formats.

The assignment covers:

- Understanding Spark Architecture (Driver, Cluster Manager, Executors)
- Understanding Client Mode and Cluster Mode
- Learning Lazy Evaluation and DAG (Lineage Graph)
- Reading CSV and Parquet files
- Schema Inference and Data Type Handling
- DataFrame Transformations
- DataFrame Actions
- Column Selection and Filtering
- Renaming Columns
- Type Casting
- Adding New Columns
- Predicate Pushdown
- Shuffle Operations
- Handling Null Values
- Building Spark Data Pipelines
- Writing Processed Data into CSV and Parquet
- Spark Performance Best Practices

# ▶️ How to Run

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project directory

```bash
cd Week-6
```

3. Install dependencies

```bash
pip install pyspark jupyter
```

4. Launch Jupyter Notebook

```bash
jupyter notebook
```

5. Open

```
Week6_Spark_Assignment_Superstore.ipynb
```

6. Run all cells.
